opencode 出口代理
发往 opencode 的请求可经代理池轮询出口；命中限流时冷却当前出口并自动跳过。支持 http / https / socks5 / socks5h，每行一个，如 socks5://127.0.0.1:1080。
-
Cline 出口代理
国内直连 Cline 上游会被跨区限制；配置后所有发往 Cline 的请求（对话、登录/令牌刷新、模型同步）经代理池轮询出去。支持 http / https / socks5 / socks5h，每行一个，如 socks5://127.0.0.1:1080。回环 / 内网地址（本机 Ollama 等自定义 Provider）始终直连；未配置时依次尝试环境变量代理、直连。

应用信息
Cline2API
Cline API 反向代理 · 多账号轮询 · 双协议兼容
版本 dev · MIT License · Go 1.25 + Wails v2
快速上手
1
添加 Cline 账号
前往「导入账号」页面，通过 OAuth 登录或手动输入 refreshToken 添加账号。支持批量导入。
2
生成 API Key
前往「密钥与安全」页面生成密钥。如不配置任何密钥，代理允许匿名访问。
3
配置客户端
在 Claude Code、Cline 等客户端中设置：
Base URL: http://127.0.0.1:3457/v1
API Key: <生成的密钥>
Model: cline-free/glm-5.2

数据与隐私
• 本程序仅在本地运行，默认监听 127.0.0.1:3457，不对外暴露。
• 账号凭据（refreshToken）存储在数据目录的 .cline-accounts.json（Docker 中位于 /app/data，可用 CLINE2API_DATA_DIR 配置）中，明文保存，请注意保护。
• 所有 API 请求通过本机代理转发至 Cline 官方服务器，不经过任何第三方。
• 关闭窗口即停止服务，无后台驻留进程。
